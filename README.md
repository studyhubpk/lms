# My LMS — Step 1

Starter frontend for a Learning Management System built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

## Step 1 includes

- Responsive LMS shell
- Login and Register screens
- Student, Teacher, and Admin dashboards
- Course cards
- Sidebar navigation
- Reusable UI components
- Sample data only

## Step 2

Connect Firebase Authentication and Firestore. Do not add passwords or secret credentials to the repository.
